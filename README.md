# GeoKG and LLM literature catalogue

This static English catalogue contains 57 subsection records representing 51 unique works. The supplied collection contains 56 PDFs across Sections 5.1-5.5, and Traff-LLM is included as a verified metadata-only Chapter 4 record because its local PDF was unavailable.

## Section counts

- Chapter 4 supplement: 1 record
- Section 5.1, Geographic question answering: 14 records
- Section 5.2, Automated spatial analysis: 12 records
- Section 5.3, Geospatial recommendation: 10 records
- Section 5.4, Spatiotemporal forecasting: 10 records
- Section 5.5, Decision support: 10 records

The same paper may appear in both Sections 5.1 and 5.2 when it supports both review topics. This is why the section-record count is higher than the unique-work count. Folder assignments from the supplied archive are preserved exactly.

Sections 5.1 and 5.2 display Method and Benchmark papers in separate groups. The entire user-facing interface is in English.

## GitHub Pages deployment

Upload all files in this folder to the repository root. In **Settings -> Pages**, deploy from the `main` branch and `/(root)`. The catalogue uses relative paths and requires no build process.
