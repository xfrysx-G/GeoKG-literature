01跨领域环境与灾害Human–environment integration

KnowWhereGraph

跨领域地理知识图谱

知识图谱、数据融合与地理增值服务

把灾害、土壤、农业、健康等数据通过空间单元与时间关联，服务跨领域环境信息发现。

A cross-domain geo-knowledge graph that connects environmental and societal data through shared spatial references, supporting geo-enrichment and contextual discovery.

团队与代表作者 / Team
UCSB等多校合作；Krzysztof Janowicz、Pascal Hitzler、Mark Schildhauer等
代表性依据 / Evidence
NSF Convergence Accelerator支持；合作涉及USGS、USDA及产业和公益机构
知识与空间表达 / Knowledge
地理实体、区域、全球离散网格及主题数据；通过空间与时间关联不同来源。
典型用途 / Applications
受灾地区背景信息整合、农业与食品供应链环境信息、跨来源区域比较。
整理价值 / Perspective
以空间位置组织跨领域证据，说明GeoKG如何承担GIS中的地理增值服务。

范围说明 / Scope
适合说明异构数据的空间关联和地理增值；不能把空间共现直接解释为因果关系。

02深时地学与地质Deep-time geoscience

DDE Geoscience Knowledge Graph

深时数字地球地学知识图谱

国际科学计划中的知识体系、图谱与协同工具

组织基础层、学科层与应用层知识，支持地学知识共享、融合与专业应用。

The DDE programme develops geoscience knowledge systems, ontologies and graphs across disciplines, combining expert organisation with knowledge extraction.

团队与代表作者 / Team
IUGS Deep-time Digital Earth计划；朱云强、周成虎、胡修棉、王新兵等多机构团队
代表性依据 / Evidence
IUGS国际科学计划及UNESCO官方介绍；有系统性方法与建设进展论文
知识与空间表达 / Knowledge
地学概念及学科关系；区分基础、学科和应用层。空间实例与专业概念层需分别说明。
典型用途 / Applications
跨学科地学知识共享、专业语义整合、面向应用的地学知识组织。
整理价值 / Perspective
国际科学计划下的专业领域知识工程，适合体现专家知识、学科本体与图谱协作。

范围说明 / Scope
DDE是计划与生态体系，不能等同于一个已完全统一的全球实例图谱。

03城市、能源与工业数字孪生Dynamic digital twins

The World Avatar

世界化身／世界数字孪生知识图谱

动态知识图谱、计算代理与数字孪生框架

连接建筑、能源、环境与模型，使用计算代理更新信息及派生结果，支持模拟和情景分析。

A dynamic knowledge graph and agent framework connecting data and computational models for interoperable digital twins and scenario analysis.

团队与代表作者 / Team
University of Cambridge、Cambridge CARES及合作团队；Markus Kraft、Jethro Akroyd等
代表性依据 / Evidence
剑桥官方持续研究项目；具有通用框架论文及洪水风险等应用研究
知识与空间表达 / Knowledge
建筑、基础设施、传感器、环境信息与计算模型；代理更新数据和派生信息，部分应用具有空间锚点。
典型用途 / Applications
建筑与能源系统分析、城市韧性、洪水评估和情景模拟；具体能力取决于应用模块。
整理价值 / Perspective
从静态事实走向数据—模型—计算代理协同，适合讨论动态GeoKG与数字孪生。

范围说明 / Scope
框架、本体与具体应用实例图谱应分开表述；并非所有模块都是地理数据。

04水文与水资源Hydrology and water data

Geoconnex

水文地理数据互联知识图谱

水数据标识、链接与检索基础设施

以持久标识关联河流、流域、监测站、数据服务与提供机构，帮助发现跨机构水数据。

A water-data linking infrastructure that uses persistent identifiers and a knowledge graph to connect hydrologic features with distributed data resources.

团队与代表作者 / Team
Lincoln Institute of Land Policy的Center for Geospatial Solutions／Internet of Water；与USGS合作
代表性依据 / Evidence
USGS官方介绍其社区水数据知识图谱与检索索引；有公开访问文档
知识与空间表达 / Knowledge
河流、流域、监测站及相关数据服务；利用持久URI连接水文参考对象与分散资源。
典型用途 / Applications
跨机构发现某条河流、流域或站点关联的数据，减少不同水数据系统间的检索障碍。
整理价值 / Perspective
侧重标识、链接和资源发现，代表跨机构水文数据互操作。

范围说明 / Scope
核心是水文对象与分散数据资源互联，不代表将全部原始观测集中存入图谱。

05海洋信息Federated ocean information

Ocean Data Information System (ODIS)

海洋数据信息系统

联邦式元数据知识图谱与互操作工程

通过分布式节点发布和采集结构化元数据，连接海洋数据、服务及其他信息资源。

A federation of independent ocean information systems whose shared metadata conventions enable a collective knowledge graph for resource discovery.

团队与代表作者 / Team
UNESCO IOC／IODE；Pier Luigi Buttigieg、Douglas Fils等参与技术建设
代表性依据 / Evidence
联合国教科文组织政府间海洋学委员会体系；跨机构海洋资源互联
知识与空间表达 / Knowledge
海洋数据集、服务与其他信息资源的结构化描述；采集分布式节点元数据并建立资源关联。
典型用途 / Applications
跨海洋机构发现数据和服务，让独立系统的资源描述可互操作。
整理价值 / Perspective
以国际协作的联邦元数据图谱实现海洋信息发现，适合与集中式实例图谱比较。

范围说明 / Scope
主要是资源描述与发现层的知识图谱，不能称为统一的原始海洋观测或海洋因果图谱。

06智慧城市与交通Smart cities and mobility

Km4City / Snap4City

城市知识模型与智慧城市平台

城市本体、实例知识库、API与运营平台

语义整合道路、地址、POI、公共交通、传感器与城市事件，支持城市服务和数据查询。

A city knowledge model and platform ecosystem integrating heterogeneous urban data into an RDF knowledge base for querying and city services.

团队与代表作者 / Team
University of Florence DISIT Lab；Paolo Nesi、Pierfrancesco Bellini等
代表性依据 / Evidence
佛罗伦萨大学研究团队；有城市知识库、服务接口与平台应用文档
知识与空间表达 / Knowledge
道路、地址、城市服务、交通传感器等；用城市本体协调静态与动态数据，并提供SPARQL访问。
典型用途 / Applications
城市数据整合、道路及服务查询、交通与传感器相关应用。
整理价值 / Perspective
展示城市本体如何落地为实例知识库、接口与应用，而非停留在概念模型。

范围说明 / Scope
Km4City本体与Snap4City平台不是同一对象；代表性在于本体与实例知识库及服务的结合。

07精确几何与空间问答Precise geospatial knowledge

YAGO2geo

具有精确地理空间知识的YAGO扩展

地理知识图谱与研究数据资源

为YAGO补充点、线、面等几何及行政区域信息，支持更精确的空间查询与地理问答。

An extension of YAGO2 with precise geospatial information and geometries, supporting spatial queries beyond simple entity coordinates.

团队与代表作者 / Team
National and Kapodistrian University of Athens；Manolis Koubarakis、Nikolaos Karalis、Georgios Mandilaras
代表性依据 / Evidence
ISWC 2019成果；雅典大学公开论文与项目资源
知识与空间表达 / Knowledge
地理实体与行政区划，以及点、线、面等精确几何；支持基于几何的空间查询。
典型用途 / Applications
空间条件检索与地理问答，以及对地理实体几何和行政关系的联合利用。
整理价值 / Perspective
适合作为语义实体与精确几何结合的研究案例。

范围说明 / Scope
属于经典研究资源；不能仅凭项目主页存在就判断其仍在持续更新。

08全球地理实体与开放地图语义化World-scale geographic entities

WorldKG

世界尺度地理知识图谱

地理知识图谱与公开研究数据

把OpenStreetMap的地理实体和标签组织成语义层级，关联Wikidata、DBpedia等外部知识。

A world-scale geographic knowledge graph that semantically organises OpenStreetMap entities and tags and connects them with external knowledge bases.

团队与代表作者 / Team
University of Bonn、L3S；Elena Demidova、Alishiba Dsouza、Nicolas Tempelmeier、Ran Yu、Simon Gottschalk
代表性依据 / Evidence
DFG研究项目；CIKM 2021论文及机构公开成果
知识与空间表达 / Knowledge
OSM地理实体、标签与语义类别层级；连接外部知识库，改善地理实体的语义表达。
典型用途 / Applications
地理实体语义检索、地图数据与通用知识库对齐、地理知识增强研究。
整理价值 / Perspective
适合作为开放地图数据从标签系统走向语义图谱的代表案例。

范围说明 / Scope
WorldKG是基于OSM构建的语义资源，不等同于OSM本身；注意数据版本时间。
