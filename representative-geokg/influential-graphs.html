01直接地理／时空知识图谱

YAGO2

时空增强型YAGO知识库

团队 / Team
Max Planck Institute for Informatics；Johannes Hoffart、Fabian M. Suchanek、Gerhard Weikum等。
代表性与引用证据 / Impact
AI Journal 2013论文获Artificial Intelligence Journal Prominent Paper Award。Max Planck Institute 2023双年报告记载该论文当时约1,500次引用；引用数随数据库和时间变化。
工程规模 / Scale
YAGO2论文报告约4.47亿事实、980万实体，并将不少实体和事实锚定到时间与空间；这是论文发布时的数据规模。
知识内容 / Graph content
从Wikipedia、GeoNames和WordNet构建实体知识，并对实体、事件及事实加入时空信息。
典型用途 / Uses
时空知识查询、实体消歧、语义搜索和关联事实发现。
综述边界 / Scope
这里的YAGO2是时空扩展图谱，区别于已有清单里的YAGO2geo：后者是在YAGO2基础上进一步增加精确几何与OSM地理要素。
代表论文 / Reference

Hoffart et al. (2013). YAGO2: A Spatially and Temporally Enhanced Knowledge Base from Wikipedia. Artificial Intelligence, 194, 28–61. DOI: 10.1016/j.artint.2012.06.001.

02直接地理知识图谱与Linked Data工程

LinkedGeoData

关联地理数据知识图谱

团队 / Team
University of Leipzig AKSW团队；Claus Stadler、Jens Lehmann、Konrad Höffner、Sören Auer。
代表性与引用证据 / Impact
Semantic Web期刊的经典GeoKG工程论文；Rankless（引用数据来自OpenAlex）检索时显示该论文有268次索引引用。引用计数依索引平台而异。
工程规模 / Scale
把协作式OpenStreetMap数据转换为RDF，建设地理词汇、实体链接、查询和浏览应用；工作不只是提出模型，也包括数据发布与互联。
知识内容 / Graph content
道路、建筑、地貌等OSM对象的RDF表达、类型词汇及与GeoNames等外部地理数据的链接。
典型用途 / Uses
空间Linked Data整合、RDF语义查询、地理浏览与跨数据源关联。
综述边界 / Scope
项目论文发表于2012年，作为奠基工程引用；不据此声称当前SPARQL端点仍然正常运行。
代表论文 / Reference

Stadler et al. (2012). LinkedGeoData: A Core for a Web of Spatial Open Data. Semantic Web, 3(4), 333–354. DOI: 10.3233/SW-2011-0052.

03大规模、多语言、协作式通用知识图谱

Wikidata

维基数据协作知识图谱（含地理知识子图）

团队 / Team
Wikimedia社区与Wikimedia Foundation生态；奠基论文作者Denny Vrandečić、Markus Krötzsch。
代表性与引用证据 / Impact
ACM页面显示2014年CACM奠基论文截至本次检索约2,714次引用；Wikidata持续由全球编辑者与机器人协作维护，规模和学术影响均突出。
工程规模 / Scale
覆盖跨语言实体与属性关系，支持坐标等数据类型；可通过Wikidata Query Service以SPARQL检索地理实体和空间信息。
知识内容 / Graph content
国家、城市、行政区、河流、山脉、建筑等实体及坐标、隶属、邻接等属性关系；其地理内容属于大型通用KG中的子图。
典型用途 / Uses
地名与实体关联、跨语言地理信息查询、外部地理数据链接，以及作为其他图谱的实体标识资源。
综述边界 / Scope
Wikidata不是专门构建的GeoKG。若纳入GeoKG综述，应标注为“含丰富地理知识的通用KG”，讨论其地理子图和互联作用。
代表论文 / Reference

Vrandečić & Krötzsch (2014). Wikidata: A Free Collaborative Knowledgebase. Communications of the ACM, 57(10), 78–85. DOI: 10.1145/2629489.

04大规模、多语言、跨领域知识图谱

DBpedia

DBpedia多语言知识图谱（含地理子图）

团队 / Team
DBpedia社区；奠基工程与论文团队包括Jens Lehmann、Sören Auer、Christian Bizer等，关联Leipzig AKSW和Mannheim Data & Web Science团队。
代表性与引用证据 / Impact
Semantic Web 2015综述工程论文，Rankless基于OpenAlex的记录显示约2.2K索引引用。其团队和开放数据工程对Linked Data生态影响显著。
工程规模 / Scale
论文介绍从111种语言Wikipedia抽取结构化知识；当时英语版图谱包含超过4亿事实、描述约370万个实体，并提供下载和SPARQL服务。数字为论文发表时数据。
知识内容 / Graph content
人物、地点、组织、事件等跨领域实体及多语言关系；其中地点、坐标、行政和地理类别构成可查询的地理子图。
典型用途 / Uses
跨语言实体检索与链接、地点背景查询、开放知识图谱互联和地理实体消歧。
综述边界 / Scope
DBpedia是通用知识图谱而非专门GeoKG。引用影响来自整体知识图谱与工程论文；用于GeoKG综述时应聚焦其地理子图。
代表论文 / Reference

Lehmann et al. (2015). DBpedia: A Large-Scale, Multilingual Knowledge Base Extracted from Wikipedia. Semantic Web, 6(2), 167–195. DOI: 10.3233/SW-140134.

分类说明

专门GeoKG强调空间关系或地理对象；通用KG也可能包含高价值地理子图。此处按知识图谱形态筛选，因此没有纳入仅提供本体、标准或地名索引的资源。

Citation numbers are source-specific snapshots, not directly comparable rankings. General-purpose knowledge graphs are explicitly marked as geography-rich graphs rather than dedicated GeoKGs.
